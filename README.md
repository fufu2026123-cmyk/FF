# 深夜小屋

《深夜小屋》是一款移动端 H5 小游戏 MVP，类型为轻悬疑逃脱、逻辑推理、找物解谜和治愈故事。当前版本使用纯 HTML、CSS、JavaScript 实现，不依赖后端、数据库、npm 或外部资源，适合后续部署到 GitHub Pages。

## 本地运行方式

直接用浏览器打开 `index.html` 即可运行。

建议使用手机浏览器或浏览器移动端模拟器查看，首版主要按 375px 宽度竖屏体验设计。

## 文件结构

```text
.
├── index.html   # 页面入口和弹窗容器
├── style.css    # 移动端视觉样式、场景、背包、弹窗
├── main.js      # 关卡配置、页面渲染、交互逻辑、进度存储
└── README.md    # 项目说明
```

## 当前系统

- 首页、关卡选择、游戏场景、底部背包、弹窗、进度存档
- **10 个可通关关卡**（含三结局系统）
- 线索笔记：点击重要线索后自动记录已知信息
- 三层提示：每关提示按钮会逐步给出方向、关键线索、接近答案的提示
- 关卡内存档：刷新后保留当前关已发现线索、背包道具、机关状态、提示次数和选中道具
- 密码锁：通过 `passwordLocks` 配置密码和错误反馈
- 通关章节卡片：通关后只提供继续或返回关卡选择，不做强制分享、分享解锁或诱导分享
- **三结局系统**：普通结局 A（继续守夜）、普通结局 B（走进光里）、隐藏真结局（永恒）
- **故事碎片收集系统**：每关通关后获得一个故事碎片（9个碎片可解锁隐藏结局）

## 故事主线

**主题**：「每个深夜，都是守夜人的故事。」

**核心设定**：
- 玩家扮演"守夜人"，在城市深夜游走，帮助无法入睡的人找到答案
- 每关是一个独立故事，但最终揭示所有故事都是守夜人自己的记忆碎片
- 第10关是"终章"：守夜人回到起点，面对最终选择

**故事线索**：
- 便利店 → 等待的人
- 花房 → 放下的释怀
- 卧室 → 记忆的灯火
- 书店 → 未完的故事
- 相馆 → 模糊的自己
- 食堂 → 错过的列车
- 邮局 → 送达的信念
- 灯塔 → 身份的觉醒
- 档案室 → 全部的真相

## 三结局系统

### 普通结局 A：继续守夜
- 条件：无限制
- 结果：回到首页，继续守夜，新的故事等待被点亮

### 普通结局 B：走进光里
- 条件：无限制
- 结果：片尾字幕 + 故事回顾（显示所有已收集的故事碎片）

### 隐藏真结局：永恒
- 条件：收集全部9个故事碎片（第1-9关通关）
- 结果：显示所有9个故事碎片 + 真结局文案
- 文案：「你拿起笔，在纸上写下了所有你想说的话——给过去的自己，给未来的自己。煤油灯亮得像太阳。你明白了：守夜人不是一个人的名字，而是每一个愿意在深夜为别人点亮灯火的人的称号。」

## 第6-10关谜题设计亮点

### 第6关：清晨食堂
- **陷阱**：外卖点餐顺序 vs 外卖小哥实际行走路线
- **误导**：玩家会认为按点餐的"冷柜→调料台→出餐口→收银台"顺序取数
- **正确思路**：路线图显示的是小哥实际走过的路线（收银台0→冷柜3→调料台7→出餐口2），只取经过顺序的最后一位数字
- **难度**：★★★☆☆（误导性强，需要仔细看路线图的红色箭头）

### 第7关：雨天邮局
- **陷阱**：包裹邮戳日期是误导，真正的线索是右下角的"退回次数"
- **误导**：日期暗示按时间顺序排列
- **正确思路**：按退回次数从少到多排列（1→2→3→4），对应格子的数字（3→7→5→1）
- **难度**：★★★★☆（需要发现退回次数藏在右下角）

### 第8关：灯塔码头
- **陷阱**：这不是数字锁，是字母锁
- **误导**：玩家会找数字密码
- **正确思路**：需要回顾前面所有关卡的故事，提取"守夜人"这三个字，首字母SYR
- **难度**：★★★★★（需要跨关卡综合推理，且思维从数字转向字母）

### 第9关：守夜人档案室
- **陷阱**：墙上照片标注的拍摄时间不是真实顺序
- **误导**：按墙上标注的序号（①④③②）取数字
- **正确思路**：每张照片背面有红笔写的真实拍摄顺序，按背面顺序重新排列后取框上数字
- **照片背面真实顺序**：②(1)→④(4)→①(3)→③(2)
- **取框上数字**：3→1→7→9
- **难度**：★★★★★（需要翻看每张照片的背面，且理解"真实顺序"vs"标注顺序"的区别）

### 第10关：永恒守夜人
- **核心**：不是谜题，是选择
- **三个结局**：继续守夜（回到首页）、走进光里（片尾字幕）、面对永恒（收集全部碎片解锁）
- **触发方式**：获得旧钢笔后，选择三个选项之一

## 存档说明

存档使用浏览器 `localStorage`，键名为 `midnight-cabin-progress-v1`。

保存内容包括：
- 已解锁关卡
- 已通关关卡
- 各关进行中的临时状态
- 当前关背包
- 当前关线索笔记
- 当前关提示次数
- 当前关机关状态
- **已收集的故事碎片列表**（progress.shards）
- **隐藏结局是否解锁**（progress.secretUnlocked）
- **已见结局列表**（progress.endingsSeen）

通关某一关后，该关的临时状态会清理，只保留通关和解锁进度。

## 部署到 GitHub Pages

1. 创建 GitHub 仓库并上传这 4 个文件。
2. 打开仓库的 `Settings`。
3. 进入 `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和根目录。
6. 保存后等待 GitHub Pages 生成访问地址。

当前项目不需要构建步骤，GitHub Pages 可以直接托管。
