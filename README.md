# 深夜小屋

《深夜小屋》是一款移动端 H5 小游戏 MVP，类型为轻悬疑逃脱、逻辑推理、找物解谜和治愈故事。当前版本使用纯 HTML、CSS、JavaScript 实现，不依赖后端、数据库、npm 或外部资源，适合后续部署到 GitHub Pages。

## 本地运行方式

直接用浏览器打开 `index.html` 即可运行。

建议使用手机浏览器或浏览器移动端模拟器查看，首版主要按 375px 宽度竖屏体验设计。

## 文件结构

```text
.
├── index.html   # 页面入口和弹窗容器
├── style.css    # 移动端视觉样式、场景、背包、弹窗
├── main.js      # 关卡配置、页面渲染、交互逻辑、进度存储
└── README.md    # 项目说明
```

## 当前系统

- 首页、关卡选择、游戏场景、底部背包、弹窗、进度存档
- 5 个可通关关卡
- 线索笔记：点击重要线索后自动记录已知信息
- 三层提示：每关提示按钮会逐步给出方向、关键线索、接近答案的提示
- 关卡内存档：刷新后保留当前关已发现线索、背包道具、机关状态、提示次数和选中道具
- 密码锁：通过 `passwordLocks` 配置密码和错误反馈
- 通关章节卡片：通关后只提供继续或返回关卡选择，不做强制分享、分享解锁或诱导分享

## 如何修改关卡数据

关卡数据集中在 `main.js` 顶部的 `levels` 数组中。每个关卡包含：

- `title`：关卡名称
- `intro`：进入关卡时的氛围文案
- `goal`：玩家目标
- `hints`：三层提示文案
- `story`：通关故事文案
- `objects`：场景中可点击物品的位置、图标和基础信息
- `sceneImage`：当前关使用的本地背景图
- `hotspots`：背景图上的透明点击热区，使用百分比定位
- `passwordLocks`：密码锁配置
- `handler`：当前关卡使用的交互处理器

如果要调整点击区域位置，优先修改对应关卡 `hotspots` 中的 `x`、`y`、`width`、`height`。这些数值都是相对于场景图片容器的百分比。`debugHotspots` 位于 `main.js` 顶部，改成 `true` 后会显示热区边框和名称，方便微调。

如果要新增复杂交互，可以新增一个 `levelHandlers` 处理器，并在对应关卡的 `handler` 字段中引用它。

## 场景图片压缩建议

- 背景图正式上线前建议压缩成 WebP。
- 单张图建议控制在 300KB～800KB，避免移动端首次加载过慢。
- 建议宽度使用 720 或 1080，竖屏比例保持 9:16。
- 后续如果图片太大，可以用 TinyPNG、Squoosh 或其他图片压缩工具处理。
- GitHub Pages 测试版可以先使用 PNG，微信小游戏正式版建议统一压缩为 WebP。

## 存档说明

存档使用浏览器 `localStorage`，键名为 `midnight-cabin-progress-v1`。

保存内容包括：

- 已解锁关卡
- 已通关关卡
- 各关进行中的临时状态
- 当前关背包
- 当前关线索笔记
- 当前关提示次数
- 当前关机关状态

通关某一关后，该关的临时状态会清理，只保留通关和解锁进度。

## 部署到 GitHub Pages

1. 创建 GitHub 仓库并上传这 4 个文件。
2. 打开仓库的 `Settings`。
3. 进入 `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和根目录。
6. 保存后等待 GitHub Pages 生成访问地址。

当前项目不需要构建步骤，GitHub Pages 可以直接托管。
