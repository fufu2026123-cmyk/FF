# 深夜小屋

《深夜小屋》是一款移动端 H5 小游戏 MVP，类型为轻悬疑逃脱、找物解谜和治愈故事。当前版本使用纯 HTML、CSS、JavaScript 实现，不依赖后端、数据库、npm 或外部资源，适合后续部署到 GitHub Pages。

## 本地运行方式

直接用浏览器打开 `index.html` 即可运行。

建议使用手机浏览器或浏览器移动端模拟器查看，首版主要按 375px 宽度竖屏体验设计。

## 文件结构

```text
.
├── index.html   # 页面入口和弹窗容器
├── style.css    # 移动端视觉样式、场景、道具栏、弹窗
├── main.js      # 游戏数据、页面渲染、交互逻辑、进度存储
└── README.md    # 项目说明
```

## 如何修改关卡数据

关卡数据集中在 `main.js` 顶部的 `levelData` 数组中。每个关卡包含：

- `title`：关卡名称
- `intro`：进入关卡时的氛围文案
- `goal`：玩家目标
- `hint`：提示按钮显示的文案
- `story`：通关故事文案
- `items`：场景中可点击物品的位置、图标和基础信息

如果要调整物品位置，修改对应物品的 `x`、`y` 数值即可，它们代表物品在场景卡片中的百分比位置。

如果要新增复杂交互，可以在 `handleSceneItem` 中按关卡分发，再新增对应的 `handleLevelX` 函数。

## 部署到 GitHub Pages

1. 创建 GitHub 仓库并上传这 4 个文件。
2. 打开仓库的 `Settings`。
3. 进入 `Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 选择 `main` 分支和根目录。
6. 保存后等待 GitHub Pages 生成访问地址。

当前项目不需要构建步骤，GitHub Pages 可以直接托管。

## 后续可扩展功能建议

- 替换 emoji 和 CSS 图形为正式美术素材。
- 增加音效开关、雨声环境音和按钮反馈音。
- 增加关卡内存档，保留已获得道具和已解开的机关状态。
- 增加更多关卡，并把关卡数据拆分为独立配置文件。
- 增加成就、收集物和章节故事回顾。
- 适配微信小游戏时，将渲染和状态管理逻辑进一步模块化。
